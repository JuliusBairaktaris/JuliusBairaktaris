# Julius Bairaktaris

M.Sc. in Industrial Engineering and Management from Universität Hamburg.
I work on Qualcomm router support in OpenWrt and the Linux kernel.

[LinkedIn](https://www.linkedin.com/in/julius-bairaktaris/) · [HackerOne](https://hackerone.com/juliusbairaktaris) · [julius@bairaktaris.de](mailto:julius@bairaktaris.de)

## Projects

- [ppe-nss firmware](https://ppenss.github.io/): self-updating OpenWrt images with PPE and NSS offload, custom builds on request.
- [openwrt-ppe-nss](https://github.com/JuliusBairaktaris/openwrt-ppe-nss): OpenWrt with Qualcomm NSS hardware offload on the upstream qca_edma/qca_ppe drivers, for IPQ807x and IPQ60xx.
- [Qualcommax_NSS_Builder](https://github.com/JuliusBairaktaris/Qualcommax_NSS_Builder): prebuilt OpenWrt NSS images for IPQ807x and IPQ60xx routers.
- [nss-packages](https://github.com/JuliusBairaktaris/nss-packages): the NSS package feed.
- [OpenWrt PR #24806](https://github.com/openwrt/openwrt/pull/24806): PPE hardware flow offload for IPQ807x, driven from nftables and tc.

Other work: [OpenWrt pull requests](https://github.com/openwrt/openwrt/pulls?q=is%3Apr+author%3AJuliusBairaktaris), [kernel patches](https://lore.kernel.org/all/?q=f%3Ajulius%40bairaktaris.de) (ath11k, mac80211, netfilter), [GCC patches](https://inbox.sourceware.org/gcc-patches/?q=f%3Ajulius%40bairaktaris.de) (MIPS), [FFmpeg pull requests](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls?state=all&poster=986) (AMF filters), [mpv pull requests](https://github.com/mpv-player/mpv/pulls?q=is%3Apr+author%3AJuliusBairaktaris) (AMF filters, playback fixes).
